TealVideo & audio downloader for Android

This is an interactive preview of the app's UI, rendered with the exact palette and metrics from ui/theme/Color.kt. The real app is native Kotlin + Jetpack Compose; the APK is built by GitHub Actions from this repo.

  • Type or paste a link, press Fetch
  • Open Choose format for the quality sheet
  • Download queues a task with live progress
  • Switch tabs below the screen; toggles in Settings work

yt-dlp does the fetching, bundled ffmpeg does the muxing and post-processing, aria2c is available for multi-connection transfers. GPL-3.0.
